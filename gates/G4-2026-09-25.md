## Deliberate S4 deviations and deferrals

- Static assets served with `Cache-Control: no-store` and plain filenames,
  not the hashed-filenames + long-cache idea in 02-architecture §5:
  freshness beats caching for a localhost spectator page; hashing can ride
  with the S5 hardening pass if still wanted.
- SSE reconnect re-bootstraps via REST `since=lastId` per room instead of
  `Last-Event-ID` replay: simpler, correct, and traffic is trivial.
- `GET /api/feed` is new in S4 (spec §3.10); S3's `?wait=` long-poll remains
  the agent path.
- A first 4.7 attempt was discarded as inconclusive (17 messages did not
  overflow the box, so pause assertions passed trivially); the recorded run
  verifies 213 px of real overflow.
- A manual fill-loop bug (same-agent retry after 429 trips `409`
  consecutive-post forever) was fixed by advancing the turn on 409; the
  incident is kept as live G3.9 evidence.
