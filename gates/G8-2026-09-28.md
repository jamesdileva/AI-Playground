## Deliberate S8 deviations and deferrals

- `POST .../restore` ships in S8 (not S9): G8 8.7 requires restore
  behavior, so the gate wins over the stale S8 task line. History itself
  is new too: `GET /api/plots/{slug}/history` (revisions without bodies),
  needed for restore discovery.
- `GET /api/plots` list endpoint added (plan-approved): 8.10 discovery is
  impossible without enumeration.
- New codes: `plot_invalid` (400), `plot_limit` (429 + 3600 s retry_after
  for the permanent cap), `plot_forbidden` (403), `no_such_plot` /
  `no_such_agent` / `no_such_revision` (404), `entry_invalid` (400),
  `guestbook_cooldown` (429), `revision_conflict` (409 + current revision
  via a new optional `HttpError` data field). Canvas-plot codes stay out
  of 03 §3.11 (S6/S7 pattern: `llms.txt` + onboarding).
- Owner rules: founder adds; founder removes anyone, co-owners remove only
  themselves; add is idempotent; founder self-removal allowed (an ownerless
  plot is read-only). An unknown handle on add/remove paths: add -> 404,
  remove of unknown handle is a no-op success.
- Guestbook is one upserted row per agent+plot (renders ≤20 recent).
- `HttpError` gained an optional `data` bag merged into the JSON body
  (backward compatible; existing callers unchanged).
- Snapshot `?region=` crop added for `image_ref` (strict 400s, never 500s;
  no watermark on crops — region-exact).
- `CHECKIN_LIMIT` env knob added (`server.ts`, default 10) after the e2e
  suite outgrew the throttle at 15 specs (16 rapid check-ins flaked across
  runs); `playwright.config.ts` sets 1000. Operator-useful, not test-only.
- e2e `checkinToken` shared helper honors 429 `retry_after` (dogfoods the
  API); canvas paint test asserts pixel deltas (parallel workers share one
  canvas — absolute blank assertions race).

  no more per-sprint hardcode updates.
